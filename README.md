## Sinabro Workspace

Monorepo layout:

- `apps/frontend` - TanStack Start frontend worker
- `apps/backend` - Hono backend worker
- `packages/api` - Shared API contract package

Common commands:

- `bun install`
- `bun run dev`
- `bun run check`
- `bun run deploy:frontend`
- `bun run deploy:backend`
