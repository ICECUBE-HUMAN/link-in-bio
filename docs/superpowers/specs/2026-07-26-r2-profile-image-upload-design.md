# R2 profile image upload design

## Goal

Implement profile image upload for the page editor using a Cloudflare R2
presigned PUT URL. The R2 bucket is `test-images`; page image objects use the
`users/profile/[filename]` key prefix.

## Decisions

- The R2 bucket is publicly readable so public profile pages can load images
  directly without a server-side image proxy or signed GET request.
- `pages.image` stores the R2 object key, not a full URL. The frontend derives
  the public URL from a configured R2 public/custom-domain base URL.
- The backend authenticates the current user and issues a short-lived upload
  URL only for an image MIME type and bounded file size.
- The filename is generated by the server from a UUID and the validated file
  extension; clients cannot choose an arbitrary object key.
- Upload completion is a separate authenticated request. It verifies that the
  object exists, deletes the page's previous object when it is an R2 key under
  `users/profile/`, updates `pages.image`, and returns the page.
- A failed upload does not change the database or delete the previous object.

## Data flow

1. The page editor requests an upload session with the file MIME type and size.
2. The backend returns `{ objectKey, uploadUrl }`.
3. The browser PUTs the file directly to R2 using the presigned URL.
4. The browser calls the completion endpoint with `objectKey`.
5. The backend confirms the object, deletes the previous profile object, and
   saves the new key in `pages.image`.
6. The editor replaces its preview with the public object URL and persists no
   temporary blob URL as page data.

## Error handling

- Unauthenticated requests return the existing unauthorized response.
- Invalid page handles, file types, sizes, missing objects, and keys outside
  the generated profile prefix are rejected with the existing validation/error
  conventions.
- If completion fails, the old page image remains intact. The newly uploaded
  object may be cleaned up by a later maintenance task; cleanup is not part of
  this first implementation.
