# 지도 아이템 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 placeholder 지도 아이템을 Mapbox GL 기반의 편집·보기 흐름으로 완성한다. 새 지도 아이템은 도쿄 중심 좌표로 생성되고, 편집 모드에서 사용자가 지도 이동·확대/축소·현재 위치·장소 검색으로 위치를 지정한 뒤 기존 grid autosave 경로를 통해 저장된다. 공개 보기에서는 저장된 위치를 읽기 전용으로 표시하고 화면 근처의 지도만 지연 마운트한다.

**Architecture:** 공유 API schema가 `latitude`, `longitude`, optional `zoom`, optional `caption` 계약을 소유한다. 프론트엔드의 map renderer는 편집 상태와 저장 command만 조정하고, Mapbox surface, viewport visibility gate, Geocoding client, 검색 UI, 오류 fallback은 별도 모듈로 분리한다. 저장은 기존 `GridEditorCommand`의 `update-data`와 editor-store autosave를 재사용하며 새 backend endpoint나 별도 상태 라이브러리를 추가하지 않는다.

**Tech Stack:** React, TypeScript, `react-map-gl/mapbox`, `mapbox-gl`, Mapbox Styles/Geocoding API v6, existing UI primitives (Button/Input/Command), Bun workspaces, Vite.

## Global Constraints

- 지도 엔진은 `mapbox-gl`, React wrapper는 `react-map-gl/mapbox`를 사용한다. MapLibre/mapcn, `react-map-gl/maplibre`는 추가하지 않는다.
- style은 다음 URL 하나만 사용한다: `mapbox://styles/justhumanb2ing/cmk406try001601pr180409zf`.
- 새 지도 아이템 기본 카메라는 Tokyo 중심 `latitude: 35.6762`, `longitude: 139.6503`, `zoom: 12`이다.
- 지도는 2D Mercator로 고정한다. pitch/bearing을 저장하지 않고 pitch 0, 회전 및 touch pitch를 비활성화한다.
- 보기 모드는 완전한 read-only다. 드래그, 스크롤 줌, 더블클릭 줌, 키보드 카메라 조작, 검색, NavigationControl, GeolocateControl을 노출하거나 활성화하지 않는다.
- 편집 모드에 들어와도 기본은 위치 편집 잠금 상태다. 위치 편집 토글을 켠 동안에만 드래그·줌·검색·Mapbox NavigationControl·Mapbox GeolocateControl을 활성화한다.
- 고정 중앙 pin/crosshair 아래의 카메라 중심을 위치로 저장한다. 지도 이동 중에는 저장하지 않고 `moveend` 또는 검색/현재 위치 선택 완료 시 한 번만 저장한다.
- 현재 사용자 위치 기능은 위치 편집 활성 상태에서만 보인다. 권한 거부·위치 조회 실패 시 기존 저장 데이터와 caption을 변경하지 않는다.
- 위치 검색은 Mapbox Geocoding API v6 direct client를 사용한다. permanent 저장 조건을 충족하는 계정/요금제/정책인지 구현 전에 확인하고, 조건을 충족하지 못하면 검색 결과를 영구 저장하지 않는 대체 정책을 사용자와 재협의한다. Search Box API는 사용하지 않는다.
- 검색어는 최소 2자, 250ms debounce, 이전 요청 abort, 최대 5개 결과, `autocomplete=true`, `permanent=true`를 사용한다. 검색 결과의 provider ID는 저장하지 않는다.
- caption은 사용자가 이미 입력한 값이면 검색 결과로 덮어쓰지 않는다. caption이 비어 있을 때만 선택 결과의 표시명을 한 번 채운다.
- Mapbox access token은 `VITE_MAPBOX_ACCESS_TOKEN`으로 브라우저에 주입하며 URL/domain restriction을 적용한다. token이 없거나 Mapbox가 초기화되지 않으면 좌표 fallback과 기존 Google Maps 링크를 표시한다.
- 공개 페이지는 `IntersectionObserver`로 viewport 또는 rootMargin 200px 이내인 지도만 마운트한다. 화면 밖으로 벗어나면 Mapbox instance를 unmount하고 저장된 camera로 다시 복원한다.
- 기존 Google Maps 외부 링크와 좌표 표시 fallback을 유지한다.
- frontend 테스트 파일은 추가하지 않고, AGENTS.md의 정책에 따라 frontend test runner도 실행하지 않는다. backend schema/controller 검증만 기존 테스트 경계 안에서 추가한다.
- 기존 editor-store, GridEditorCommand, RGL drag cancel 계약을 재사용한다. 새 map 전용 store, backend geocoding proxy, map item별 style 설정은 만들지 않는다.

**Files:**

```ts
export type MapSearchResult = {
  id: string;
  name: string;
  address?: string;
  latitude: number;
  longitude: number;

export type MapboxGeocodingErrorCode =
  | "missing-token"
  | "invalid-query"
  | "http"
  | "invalid-response"
  | "network";

export class MapboxGeocodingError extends Error {
  readonly code: MapboxGeocodingErrorCode;
  readonly status?: number;
}

export type SearchMapboxLocationsOptions = {
  accessToken?: string;
  language?: string;
  signal?: AbortSignal;
};

  query: string,
  options?: SearchMapboxLocationsOptions,
```

**Steps:**

- [ ] `query.trim()`이 2자 미만이면 network request 없이 `invalid-query` 오류를 발생시키는 정책을 구현하고, UI가 이를 validation 상태로 표시할 수 있도록 한다.
- [ ] Mapbox Geocoding v6 forward URL을 `URL`/`URLSearchParams`로 만든다. 다음 query parameter를 명시한다: `q`, `autocomplete=true`, `limit=5`, `language`(설정 시), `permanent=true`, `access_token`.
- [ ] `fetch`에 전달된 `AbortSignal`을 지원한다. AbortError는 상위 UI가 정상적인 취소로 무시할 수 있도록 원래 abort를 보존한다.
- [ ] non-2xx 응답에는 status를 포함한 `MapboxGeocodingError(code="http")`를 던진다. JSON parse 실패, features 누락, geometry가 Point가 아님, coordinates가 finite하지 않으면 `invalid-response`를 던진다.
- [ ] GeoJSON feature에서 provider id, display name, optional address, Point 좌표만 추출해 `MapSearchResult`로 정규화한다. raw feature/properties를 반환하거나 저장 계층으로 전달하지 않는다.
- [ ] token이 없으면 요청 전에 `missing-token` 오류를 발생시킨다. 호출자가 token을 직접 전달하지 않으면 `VITE_MAPBOX_ACCESS_TOKEN`을 기본값으로 사용한다.
- [ ] Geocoding 공식 문서의 permanent storage 조건을 README나 코드 comment로 새로 복제하지 말고, 구현 전 확인 결과를 계획 실행 기록에 남긴다. Search Box API를 import하거나 endpoint로 사용하지 않는다.

```tsx
export type MapboxMapSurfaceHandle = {
  flyTo(camera: MapCamera): void;
};

export type MapboxMapSurfaceProps = {
  accessToken: string;
  camera: MapCamera;
  interactive: boolean;
  onMoveEnd(camera: MapCamera): void;
  onGeolocate(camera: MapCamera): void;
  onGeolocateError(error: unknown): void;
  onError(error: unknown): void;
```

**Steps:**

- [ ] `MapViewportGate`를 SSR-safe하게 구현한다.
  - 초기 render에서는 layout-preserving placeholder를 사용한다.
  - browser에서만 `IntersectionObserver`를 생성한다.
  - rootMargin은 `200px 0px`로 설정하고, `isIntersecting`이 false가 되면 children을 unmount해 Mapbox instance를 해제한다. 다시 rootMargin 안으로 들어오면 저장된 camera로 새 instance를 mount한다.
  - `forceMount`는 edit mode + location editing 상태에서 viewport 밖이어도 즉시 surface를 mount하기 위한 escape hatch로 사용한다.
  - observer가 없는 환경에서는 children을 mount해 기능을 막지 않는다.
- [ ] `MapboxMapSurface`에서 `react-map-gl/mapbox`의 `Map`을 사용하고 `mapLib={import("mapbox-gl")}`를 지정해 Mapbox runtime을 lazy chunk로 분리한다. Mapbox CSS는 surface module 또는 전역 entry에서 한 번만 import한다.
- [ ] Map에 다음 초기/제약 props를 적용한다.
  - `mapboxAccessToken`: 전달받은 token
  - `mapStyle`: `MAPBOX_STYLE_URL`
  - `initialViewState`: camera의 longitude/latitude/zoom
  - `projection="mercator"`
  - `pitch={0}`, `maxPitch={0}`
  - `dragRotate={false}`, `touchPitch={false}`
  - `minZoom={0}`, `maxZoom={22}`
- [ ] `interactive`가 false일 때 `dragPan`, `scrollZoom`, `doubleClickZoom`, `keyboard`를 false로 전달하고, true일 때만 해당 camera interactions를 켠다. rotation/touch pitch 관련 조작은 항상 끈다.
- [ ] `interactive`가 true일 때만 Mapbox `NavigationControl`을 렌더링한다. zoom buttons는 표시하고 compass는 숨긴다. `GeolocateControl`도 true일 때만 렌더링하며 `trackUserLocation={false}`로 one-shot current location 동작을 사용한다.
- [ ] surface 중앙에 fixed pin/crosshair overlay를 배치한다. overlay는 `pointer-events: none`으로 지도 pointer event를 가로채지 않으며, 위치 변경은 map center에서 읽는다.
- [ ] `onMoveEnd`는 move event의 longitude/latitude/zoom을 finite 값으로 검증해 MapCamera로 전달한다. event 중간에는 parent command를 호출하지 않는다.
- [ ] `onGeolocate`는 geolocation event의 coords.longitude/latitude와 현재 camera zoom을 MapCamera로 전달한다. reverse geocoding은 하지 않는다.
- [ ] `onGeolocateError`는 permission denied/timeout/unavailable 이벤트를 parent의 non-destructive status로 전달하고, `onError`를 통해 map fallback으로 전환하지 않는다.
- [ ] ref의 `flyTo`는 map instance의 `flyTo`를 호출한다. prefers-reduced-motion일 때 duration 0, 그 외 duration 450ms를 사용하고, after moveend가 parent 저장을 담당하도록 한다.
- [ ] Mapbox error를 surface 내부에서 무시하지 말고 `onError`로 한 번 전달한다. fallback 전환 후 retry가 가능하도록 parent가 surface를 재마운트할 수 있는 구조를 유지한다.
- [ ] `MapFallback`는 동일한 map container 높이와 중앙 정렬을 유지하면서 좌표를 보여주고, 기존 Google Maps URL(`https://www.google.com/maps/search/?api=1&query=lat,long`)로 이동하는 anchor와 retry callback을 제공한다. token missing, style load failure, geocoding와 무관한 map initialization failure를 모두 같은 fallback contract로 처리한다.

카메라 저장은 기존 update-data command를 통해서만 수행한다.

```ts
function commitCamera(
  nextCamera: MapCamera,
  nextCaption = item.data.caption,
) {
  if (isSameMapCamera(normalizedCamera, nextCamera)
      && nextCaption === item.data.caption) {
    return;
  }

  onCommand({
    type: "update-data",
    itemId: item.id,
    data: {
      ...item.data,
      latitude: nextCamera.latitude,
      longitude: nextCamera.longitude,
      zoom: nextCamera.zoom,
      caption: nextCaption,
    },
  });
}
```

**Steps:**
